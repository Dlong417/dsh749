# 7/49 周期规则推演与验证助手

一个纯静态的网页程序：内置 2438 期历史数据（2020-03-07 ~ 2026-11-19），每天录入一期开奖，自动生成带生肖的下一期组合，并逐期验证规则是否还有效。

## 部署到 GitHub Pages（不需要装任何软件）

1. 登录 GitHub，点右上角 **+ → New repository**
2. 仓库名填 `dsh749`（随便），选择 **Public**，点 **Create repository**
3. 进入仓库，点 **Add file → Upload files**
4. 把本文件夹里的 `index.html` 和 `.nojekyll` 两个文件拖进去，点 **Commit changes**
5. 仓库页 → **Settings → Pages**
6. **Source** 选 `Deploy from a branch`，**Branch** 选 `main`，目录选 `/ (root)`，点 **Save**
7. 等 1~2 分钟，访问 `https://你的用户名.github.io/dsh749/`

> `.nojekyll` 是空文件，作用是让 GitHub 不要用 Jekyll 处理页面。上传时如果看不到它，可以在仓库里 **Add file → Create new file**，文件名填 `.nojekyll`，内容留空，提交即可。

## 手机上使用

- 用手机浏览器打开上面的网址即可，页面已做响应式适配（号码输入自动换行、按钮全宽、表格可横向滑动）。
- iPhone Safari：分享 → **添加到主屏幕**；Android Chrome：菜单 → **添加到主屏幕**。之后像 App 一样打开。

## 数据说明

- 页面首次打开会加载内置的 2438 期数据。
- 你录入的新期数、预测记录保存在**浏览器的 localStorage** 里，只存在当前设备。
- **手机和电脑的数据不互通**。要迁移：在一台设备上点「导出 JSON」，把文件发到另一台，再点「导入 JSON」。
- 如果你有更新的表格：Excel 另存为 CSV（UTF-8），在页面点「导入 CSV（最新数据）」即可整体替换。

## 规则（v6.1）

- R1~R15：与近 1~15 期并集的重合数，各自落在历史 80% 区间
- R16 和值 129~220；R17 奇数 2~6；R18 大号 2~5；R19 连号 ≤2；R20 区间数 4~6；R21 跨度 32~47
- 合规组合中按「近 1~6 期出现次数加权」（1 / 0.88 / 0.61 / 0.33 / 0.32 / 0.14）取分数最高
- 特码：取最低分且不等于上期特码

## 结论与边界

- 全历史回测约 1.05（z≈1.8），2021 年曾低至 0.92，优势不稳定；
- 结构规则只能保证组合「像真实的一期」，不能保证「更容易中」；
- 任意 7 个号码组合的中奖概率都是 1/85,900,584。

## 更新方法

以后要更新（改了数据或规则）：把新的 `index.html` 上传覆盖仓库里的旧文件即可，Pages 会自动重新发布。
